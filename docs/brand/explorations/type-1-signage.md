# Type 1: Signage

- **Display:** Big Shoulders Display, variable (100 to 900). `@fontsource/big-shoulders-display`, OFL-1.1.
- **Text:** Atkinson Hyperlegible Next, variable (200 to 800), with italic.
  `@fontsource/atkinson-hyperlegible-next`, OFL-1.1.

**The idea.** Big Shoulders is a condensed face drawn from a city's signage: bridges, painted
shopfronts, street names. Set in capitals it stands tall and narrow, like figures with long shadows,
and its narrowness lets very large words fit across a phone screen, which kinetic type needs.
Atkinson Hyperlegible Next was designed so that easily confused letters (I, l and 1; O and 0) never
are.

**Why it fits a night café.** The display gives the city and its streets a voice. The text face
answers the anti-goal "text hard to read" directly, which matters on dark backgrounds, where thin
type blurs.

**Kinetic use.** Letters rise one by one from a baseline; the condensed shapes keep the motion tidy
even at very large sizes.

**Watch.** Atkinson has a slashed zero. That helps with order codes but looks slightly technical in
times like 03:00.
