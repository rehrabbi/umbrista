# Palette 1: Sodium

**The idea.** Navy ink, and the orange of a sodium street lamp. Sodium light is the colour cities
used to be at night, and it is warm without being brown. Crema is a pale, sandy tone kept for small
details.

**Why it fits.** Blue and orange are opposites, so the single lamp colour stands out sharply against
the night, which is exactly its job: actions, "open now", the lit window. The day set is an overcast
late afternoon: cool blue-grey, the lamps not yet lit, the signal darkened to an unlit amber.

| Role | Night | Day |
|---|---|---|
| Background | Ink `#0D1524` | Overcast `#DCE3EC` |
| Surface | Dusk `#15203A` | Paper `#EEF2F6` |
| Text | Glass `#E4E8EF` | Ink `#0D1524` |
| Quiet text | Rain `#97A3B8` | Slate `#46536A` |
| Signal | Sodium `#F4A13A` | Unlit sodium `#965000` |
| Crema (sparingly) | `#D3B48C` | `#7E6040` |

All text pairs pass WCAG AA, and most night pairs pass AAA; the board lists the computed ratios. Day
crema passes only for large text and details (4.47:1), and is never used for body text.

**Watch.** The day signal `#965000` is a dark amber. Next to cool greys it reads as amber, but on a
warm background it would drift towards coffee-brown.
